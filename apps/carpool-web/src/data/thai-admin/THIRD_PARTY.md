# Thai administrative geography

District and province names, TIS 1099 codes, and polygon-derived centroids
come from **thailand-canonical-admin-names** v1.0.0 by William J. Reynolds.

- Source: https://github.com/DevelopedbyWill/thailand-canonical-admin-names
- Data license: **Creative Commons Attribution 4.0 International (CC BY 4.0)**
  https://creativecommons.org/licenses/by/4.0/
- Tables used: `data/v1.0.0/thailand-adm1-provinces-v1.0.0.csv` (77)
  and `data/v1.0.0/thailand-adm2-districts-v1.0.0.csv` (928)
- Bundled polygons in that project inherit OCHA COD CC BY 3.0 IGO; this
  repo only copies name/code/centroid columns, not polygons.

Bangkok’s listed pin in the carpool UI is Bell’s city-center
(13.7563, 100.5018), not the dataset’s polygon centroid.
